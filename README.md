# VELOUR

A premium minimal fashion eCommerce storefront — Next.js (App Router) + TypeScript, no CSS framework.

```bash
npm install
npm run dev            # http://localhost:3000
npm run build && npm start
```

## Structure

```
app/                       routes, root layout (Navbar/Footer/providers), globals.css (design system)
components/                shared + page-level components (server by default; "use client" only where needed)
lib/data.ts                Product type, CATEGORIES, BASE_PRODUCTS (demo), PRODUCTS (active catalogue), subcategoriesFor()
lib/generated-products.ts  imported listings — regenerated by the import script, never hand-edited
lib/api.ts                 mock async service layer — THE backend-swap seam
lib/store.tsx              cart context + localStorage persistence
lib/format.ts              money() + shipping helpers
scripts/import-listings.mjs  CSV → products importer
incoming/                  listings-template.csv, README.md, images/ drop folder
```

Routes: `/`, `/women`, `/men` (`?sub=…&sort=…`), `/product/[id]`, `/search?q=…`, `/cart`, `/checkout`, `/login`, `/about`, `/contact`, `/privacy`.

## Swapping the mock for a real backend

Pages and components never import `PRODUCTS` directly — they call the async functions in `lib/api.ts`
(`getProducts`, `getProductById`, `getFeatured`, `getNewArrivals`, `getTrending`, `getRelated`, `getAllProductIds`).
Replace each body with a `fetch()` to your API, keeping signatures and return types:

```ts
export async function getProductById(id: string) {
  const res = await fetch(`${process.env.API_URL}/products/${id}`, { next: { revalidate: 60 } });
  return res.ok ? ((await res.json()) as Product) : undefined;
}
```

No page-level changes needed. (The navbar's live search also uses `getProducts` client-side — point it at a
public endpoint or a route handler when you swap.) Cart state stays client-side in `lib/store.tsx`; replace its
persistence with API calls when you add accounts.

## Adding products (listings pipeline)

See [`incoming/README.md`](incoming/README.md): fill `incoming/listings.csv`, drop images in `incoming/images/`,
run `npm run import-listings`. To show only imported products, change the `PRODUCTS` line in `lib/data.ts`
to `export const PRODUCTS: Product[] = GENERATED_PRODUCTS;`.

## Hero video

The hero plays `public/videos/hero.mp4` (muted, looping, poster `public/images/hero-poster.jpg`). To change it, transcode a
new source with
`ffmpeg -i in.mp4 -vf "scale=-2:'min(1080,ih)'" -c:v libx264 -pix_fmt yuv420p -an -movflags +faststart public/videos/hero.mp4`
and extract a poster frame to `public/images/hero-poster.jpg`.
